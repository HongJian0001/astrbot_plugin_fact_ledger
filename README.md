# 成长台账（fact_ledger）

把「会变的数值」从记忆里拆出来单独托管：体重、攒钱、连续打卡、学习进度、关系阶段……

每个指标是一个**状态机**：当前值 / 上一次值 / 目标 / 规则 / 步长 / 变化记录（含原因与证据）。
对话时把当前状态注入上下文，模型**以台账为准**，不再自己编数字。

## 快速开始

1. 安装插件，重载/重启 AstrBot
2. 打开插件配置页，先看「身份卡 / 可变 / 私密 / 规则」四组字段（21 项）
3. 发一条 `/台账`，确认能看到示例指标或你自己的指标
4. 用 `/台账 加 <key> <名称> <单位> <初值> <目标> <规则> <步长> [daily@15:00]` 新增指标

首次安装会自动创建一个「示例·读书进度」，可以用 `/台账 删 demo_progress` 删掉。

## 为什么需要它

记忆插件擅长「发生过什么」，但数值类事实（体重到底是 106 还是 112？）会互相打架：

- 摘要平均 275 字、一条塞 40 个事件，具体数字被稀释；
- 新旧数值同时 active，没有「新值覆盖旧值」；
- 每次回答都让模型现编，数字自然漂移。

台账把这类状态变成**确定值 + 变化链**，从根上消除漂移。

## 六种规则

| 规则 | 行为 | 适合 |
|---|---|---|
| `decrease` | 每次 `-step`，到 `target` 停 | 体重、欠款 |
| `increase` | 每次 `+step`，到 `target` 停 | 攒钱、学习时长 |
| `streak` | 有事件 `+1`，断一天归零 | 早睡打卡、连续运动 |
| `stage` | 只进不退 | 关系阶段、技能等级 |
| `counter` | 只累加 | 日记篇数、运动次数 |
| `gauge` | 手动/事件设值 | 心情、体力 |

## 面板

插件详情里会多出一个「台账面板」页面：

- **身份卡**：肤色、发型、瞳色、五官、特殊体征、常用表情（固定，以人设为准）
- **可变状态**：体重、身高、目标、进度条、最近变化
- **私密属性**：三围、罩杯（仅展示在面板，群里/对话里不会主动出现）

卡片上可以直接「改值」和「推进」，等价于 `/台账 改` 和 `/台账 推进`。

## 指令

```
/台账                                  查看全部
/台账 详情 <key>                       看变化与证据
/台账 目标 <key> <数值> [YYYY-MM-DD]    改目标（可带截止日期）
/台账 改 <key> <数值> [原因]            手动设值
/台账 推进 <key> [原因]                 手动推进一步
/台账 加 <key> <名称> <单位> <初值> <目标> <规则> <步长> [daily@15:00]
/台账 删 <key>
```

## LLM 工具

- `fact_ledger_get(key, detail)` — 查询
- `fact_ledger_advance(key, reason)` — 推进「事件类」指标（decrease/increase 会被拒绝，避免模型改体重）

## 随机浮动（更像真人）

递减/递增类指标可以配置「不是每次都成功」：

```json
"flat_probability": 0.25,   // 25% 概率今天没变化（平台期）
"gain_probability": 0.12,   // 12% 概率略微回升
"gain_step": 0.2,           // 回升幅度
"ceiling": 114.0            // 上限，防止越减越胖
```

净趋势仍然向下，但会出现平台期和小幅反弹。

## 目标与截止日期

模型可以自己定目标（工具 `fact_ledger_set_target`），管理员也可以：

```
/台账 目标 weight_jin 104 2026-12-31
```

过了截止日期就不再推进，也不会补扣。

## 回写记忆（可选）

打开 `memory_sync_enabled` 并填 `memory_sync_metrics` / `memory_sync_target_id` 后，
指标每次变化都会 upsert 成 memory_companion 里**唯一一条核心事实块**（例如「当前体重」），
覆盖旧值而不是新增，内容带日期、原因和目标。

这样记忆里不会同时存在几个互相矛盾的数值。
