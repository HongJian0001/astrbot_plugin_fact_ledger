# 成长台账（fact_ledger）

让机器人有「会变的数值」：体重、攒钱、连续打卡、学习进度、技能熟练度……
每个指标都是一个**状态机**，每次变化都带时间、原因和证据。回答时以台账为准，不让模型编数字。

> 记忆插件擅长「发生过什么」，台账负责「现在是多少、为什么变了」。

## 它解决什么问题

- 体重今天 110、明天 106、后天又说 112？→ 台账只有一个当前值，改一次记一次
- 说好每天称体重，到点却忘了？→ 到点提示「待确认」，她确认后才改数
- 「我在练穿高跟鞋」练了几次、到哪一级了？→ 技能熟练度，练一次加一次
- 她答应的事转头就忘？→ 关键约定可以写进长期记忆（可选）

## 日常怎么用（不用记指令）

直接说话就行：

| 你说 | 她会做什么 |
|---|---|
| 帮我记一下，今天 110.6 斤 | 记录体重，并告诉你掉了多少 |
| 我在减肥，目标 90 斤 | 设目标（会走确认流程） |
| 我想练穿高跟鞋走路，每周两三次 | 生成提案，你回「同意」后开始记录 |
| 今天穿高跟鞋走了半小时 | **自动记一次练习**（+熟练度） |
| 你最近练得怎么样 | 读台账回答你 |
| 以后改成每周五次 | 直接改练习频率（你的指令就是同意） |
| 你三围多少 | 只有你私聊问才回答，群里一律不说 |

## 常用指令（两个就够）

```
/台账           查看所有指标
/技能进度        查看技能熟练度（别名 /技能）
```

`/技能进度` 会显示：

```
🎯 技能进度

· 穿高跟鞋走路（skill_highheels）
  熟练度 46/100  ████░░░░░░  熟练
  距「精通」还差 24 点
  已练 12 次
  上次练习：2026-11-23（2 天前）
  频率参考：每周两三次（不打卡）
  每日上限：8 点（今天已得 0）
```

## 进阶指令（管理员）

日常用不到，需要精细控制时再用。

| 指令 | 作用 |
|---|---|
| `/台账 详情 <key>` | 看某个指标的全部变化记录与证据 |
| `/台账 新建技能 <名称> [频率参考]` | 建一个技能（自动生成 key） |
| `/台账 练习 <key> [次数] [说明]` | 手动记一次练习 |
| `/台账 频率 <key> <自由文本>` | 改练习频率，例如「每周五次」 |
| `/台账 目标 <key> <数值> [YYYY-MM-DD]` | 改目标，可带截止日期 |
| `/台账 改 <key> <数值> [原因]` | 手动设值 |
| `/台账 推进 <key> [原因]` | 手动推进一步 |
| `/台账 提案` / `批准 [id]` / `驳回 <id>` | 处理她提的任务/改频率提案 |
| `/台账 加 <key> <名称> <单位> <初值> <目标> <规则> <步长> [节奏]` | 高级：手动新建任意指标 |
| `/台账 删 <key>` | 删除指标 |

> `key` 是内部英文标识（如 `weight_jin`、`skill_highheels`），普通用户不用记；
> 建技能直接说「我想练 XX」或者用 `/台账 新建技能 名称` 就行。

## 七种规则

| 规则 | 行为 | 适合 |
|---|---|---|
| `decrease` | 每次 `-step`，到 `target` 停 | 体重、欠款 |
| `increase` | 每次 `+step`，到 `target` 停 | 攒钱、学习时长 |
| `streak` | 有事件 `+1`，断一天归零 | 早睡打卡、连续运动 |
| `stage` | 只进不退 | 关系阶段、技能等级 |
| `counter` | 只累加 | 日记篇数、运动次数 |
| `gauge` | 手动/事件设值 | 心情、体力 |
| `fixed` | 固定属性，人工维护 | 身高、外貌特征 |

## 技能熟练度怎么算

技能不是「读数」，是「累计经验」，所以必须由练习驱动。

| 熟练度 | 等级 |
|---|---|
| 0–20 | 生疏 |
| 21–45 | 入门 |
| 46–70 | 熟练 |
| 71–90 | 精通 |
| 100 | 掌握 |

- **按次数**累计：生疏 +5 / 入门 +4 / 熟练 +3 / 精通 +2
- **每日上限 8 点**，一天练三次也最多 8
- 3 天不练开始 **-1/天**，到「熟练」后不再衰减
- 练到 100 标记「已掌握」，永久固定

### 练习是她自己的

- ✅ 她描述自己完成了（「我今天穿高跟鞋走了半小时」）→ 记一次
- ✅ 你让她练、她确认做了（「你去练两圈」→「我走完了」）→ 记一次
- ❌ 你说「**我**今天穿高跟鞋走了半小时」→ 那是你的经历，不算她的练习
- ❌ 只提到、计划、假设、回忆 → 都不算

记完之后她**必须用一句话告诉你**：练了什么、熟练度变化、离下一级还差多少。

### 频率只是参考，不是打卡

- 频率（每周两三次 / 每周五次）只用于她自己判断该不该练
- **不会到点推送、不会催、不会算考勤**
- 她结合「已练次数 + 上次练是几天前 + 频率」自己决定要不要主动练

### 她不能自己加任务

- 想加新技能 / 改频率 → 只能**提提案**
- 你回「同意」或 `/台账 批准 <id>` 才生效
- 你**直接说**「改成每周五次」→ 直接生效（你的指令就是同意）
- 限额：每天最多 2 个提案，待批准最多 3 个，7 天过期

## 随机浮动（更像真人）

递减/递增类指标可以配置「不是每次都成功」：

```json
"flat_probability": 0.25,   // 25% 今天持平（平台期）
"gain_probability": 0.12,   // 12% 略微回升
"gain_step": 0.2,           // 回升幅度
"ceiling": 114.0            // 上限，防止越减越胖
```

净趋势仍然向下，但会有平台期和小幅反弹。

## 身份卡与私密属性

- **身份卡**（肤色/发型/瞳色/五官/特殊体征/表情）：以人设为准，台账只做镜像，冲突时用人设
- **可变数值**（体重/身高/目标）：以台账为准，和记忆或旧对话冲突时也用台账
- **私密属性**（三围/罩杯）：只在主人私聊提问时回答，群里不出现

## 配置页

插件配置页可以直接查看和修改指标（带【身份卡】【可变】【私密】【规则】分组），
其中「技能每日上限（点）」控制每个技能每天最多涨多少熟练度（默认 8，范围 1~30）。
台账变化时配置页会自动回写，不会出现「面板显示旧值」的情况。

## 记忆联动（可选）

打开 `memory_sync_enabled` 后，指标变化会把最新值 upsert 成记忆插件里唯一一条核心事实，覆盖旧值不新增。

技能还有三个里程碑会写进长期记忆：
1. 批准新技能时
2. 升到「熟练」时
3. 练到「掌握」时

## 数据

`data/plugin_data/astrbot_plugin_fact_ledger/ledger.json`（原子写入，删除即重置）

- `history`：变化记录（时间/原值/新值/原因/证据）
- `target_history`：目标调整记录
- `frequency_history`：练习频率调整记录
